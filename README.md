# Silla Global Frontier Systems Landing Page

This is the deployment-ready v1 static landing page for Silla Global.

## Deployment

Deploy this repository to Vercel as a static site. The main file is `index.html`.

## Notes

The application form is front-end only for v1. It validates required fields, shows a success modal and opens a prepared email draft to `partners@silla.global` using a mailto fallback. For production intake, connect the form to a secure backend, CRM, Airtable, HubSpot, Supabase, or Vercel serverless function.
